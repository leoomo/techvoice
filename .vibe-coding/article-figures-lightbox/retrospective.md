# 复盘总结 (Retrospective) - article-figures-lightbox

## 1. 任务背景与交付目标
- **业务诉求**: 用户提出“文章的图表如何体现呢？”，并选定了“方案 1（正文内嵌图表卡片 + 点击全屏预览 / Lightbox）”，要求自动化完成并发布上线。
- **交付目标**:
  1. 将原书 11 章节中的 114 处技术架构图与插图完整结构化映射并部署到站点中；
  2. 正文字幕流内嵌自适应图表卡片，支持中英文双语图表自适应切换；
  3. 双主题视觉与防眩设计：暗黑模式深海毛玻璃与防眩白板衬底，明亮模式微暖纸感；
  4. 交互防误触双保险：杜绝查看图片点击时误触发音频跳转；
  5. 全屏沉浸预览弹窗（Lightbox），支持 ESC 键、关闭按钮、遮罩点击退出及局部无级中英对比切换；
  6. Service Worker 升级至 v8 离线预缓存；
  7. 保证全量 14 套测试套件 100% 绿灯，快进合并至 master 并推送发布。

## 2. 核心架构与工程亮点
1. **纯净沙箱与防御性安全设计**:
   - 135 个图表文件中绝大多数为矢量 SVG，为彻底杜绝 SVG 内部潜在的 XSS 攻击（如 `<script>` 脚本注入或外链利用），全站坚决统一采用原生 `<img src="..." />` 进行沙箱隔离渲染；
   - 所有动态文字（图表标题、章节名、编号）统一使用 `escapeHtml` 与 DOM `textContent`，杜绝任何潜在的 HTML 注入。
2. **防误触双保险机制**:
   - 既有阅读器卡片绑定了点击直接跳转播放对应音频句子的逻辑（`seekToCue`）。在图表卡片内，不仅在内层点击事件派发了 `e.stopPropagation()`，而且在外层句卡片的点击事件监听器首行强制加入了 `if (e.target.closest('.cue-figure-card')) return;`，双保险防御任何冒泡穿透与事件委托误判。
3. **局部状态机与视口稳定性**:
   - Lightbox 内部提供了独立的中/英图表切换按钮。该切换仅作为 Lightbox 内部的局部状态切换，**绝对不派发全局 `langchange` 事件**，更不触发背景阅读器正文的重排与重绘，确保弹窗关闭后读者的阅读与播放焦点丝毫不受干扰。
4. **位图体积无损压缩与移动端体验**:
   - 将 2.5MB 的超大注意力热力图 `fig2-7.png` 使用专业重采样算法压缩至 300KB（体积缩减近 90%），大幅削减带宽消耗与首屏白屏时间。

## 4. 经验与最佳实践 (Learnings)
- 在 Node.js 轻量 mock 环境下，对动态创建元素的属性同步（如 `dataset` 与 `setAttribute`）以及动态创建后根据 `id` 检索注册机制，应提前做好全链路兼容，确保在轻量无头单测中能够 100% 仿真浏览器环境的行为。
- 架构分层上，将视觉表现、局部交互组件与全局播放状态机清晰解耦，是保证长期迭代高内聚、低耦合、零回归的关键。
