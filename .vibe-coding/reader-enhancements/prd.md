# PRD: reader-enhancements (有声阅读器全流程体验优化)

## 1. 背景与问题
- **痛点 1（进度丢失）**：全书 21 小时，单章最长 171 分钟。用户离开页面或误刷新后，播放位置直接重置到 00:00，严重影响长时间碎片化听书的连续性。
- **痛点 2（锁屏失控）**：移动端息屏放入口袋或使用蓝牙耳机（AirPods等）时，未接入 MediaSession API，锁屏界面无封面、无书名小节名，耳机切章/快进失效。
- **痛点 3（检索缺失）**：全书 8,052 句技术字幕与 293 个子章节，包含大量前沿 Agent 架构词汇，读者无法按关键词跨章节检索，难以作为技术参考工具。
- **痛点 4（缓冲不透明）**：Seekbar 无预缓冲指示，弱网时读者无法获知音频流加载状况。
- **痛点 5（引用不便）**：无针对特定句子的深链接分享机制。
- **痛点 6（夜间听书体验）**：缺少睡眠定时与平滑淡出，睡前听书会无休止播放。
- **痛点 7（首屏冗余加载）**：首屏全量同步加载全部 12 章数据脚本（约 2.8MB），浪费带宽与首屏解析时间。
- **痛点 8（社交卡片缺失）**：缺少 Open Graph / Twitter Card 标签，分享至社媒或通讯软件时无富媒体卡片。

## 2. 目标用户
- AI 开发者、研究员、技术架构师、学生：在日常通勤、散步、睡前或运动时，通过英文听书精进技术英文与系统设计。

## 3. 核心使用场景
- **场景 A（断点续播）**：用户在地铁上听到第 2 章第 45 分钟，到站关闭页面；晚上回到家打开网页，系统自动恢复到 45 分钟，或弹出 Toast 提示恢复，一键无缝续听。
- **场景 B（移动锁屏与耳机盲操）**：用户在散步时将手机熄屏放入口袋，锁屏界面显示“深入理解 AI Agent · Chapter 2: 上下文工程”与专著封面；敲击耳机可暂停/继续，下一曲切换下一章，长按快进/快退 5 秒。
- **场景 C（概念精准检索）**：用户在做架构调研想听“ReAct 模式与反思机制”，按下 `Cmd+K` 或 `/` 输入 `ReAct`，结果瞬时列出全书出现的句子并附带章节与时间戳，点击直接秒级定位播放。
- **场景 D（单句引用分享）**：用户在 Twitter 或即刻讨论 Prompt Engineering，点击某句卡片的“复制链接”，获得带精准时间戳的链接，他人点开直接播放该句。
- **场景 E（睡前听书定时）**：用户设定“30分钟后停止”，倒计时结束前 10 秒音量平滑线性淡出并自动暂停。
- **场景 F（快速加载）**：进入页面只快速加载当前章节数据，秒开体验极佳。

## 4. 功能范围（In Scope）

### 4.1 播放进度智能记忆与断点续播
- **节流存储**：在 `timeupdate` 中节流（2秒）将当前章节播放秒数写入 `localStorage`（键名 `ai_agent_pos_{chapterKey}`）。
- **起跳门槛**：仅在 `5s <= pos <= duration - 5s` 时记录并触发恢复；小于 5 秒视为刚开始，大于 `duration - 5s` 视为已听完，进入时均从 00:00 开始。
- **生命周期守卫**：Seek 操作必须挂载在 `loadedmetadata` 或 `canplay` 守卫中执行，在媒体元数据完全就绪（`duration` 有效）后才执行精准 `currentTime` 赋值，避免 iOS / 移动端 Safari 静默重置。
- **恢复提示与交互**：成功恢复时浮现微型 Toast 提示：“已恢复至上次进度 45:12 [从头开始]”。点击“[从头开始]”立即将 `audio.currentTime = 0`，并同步将 `localStorage` 中该章进度重置为 0。

### 4.2 系统级 MediaSession API 支持
- **元数据展示**：在播放和切章时挂载 `navigator.mediaSession.metadata`（Title 为章节小节名，Artist 为 `李博杰 · Bojie Li`，Album 为 `深入理解 AI Agent · AI Agents in Depth`，Artwork 为 `assets/icon.svg` 与高分辨率图标）。
- **动作语义明确**：
  - `play` / `pause`: 播放与暂停切换。
  - `seekbackward` / `seekforward`: 默认快退 5 秒 / 快进 5 秒。
  - `previoustrack` / `nexttrack`: 规范映射为**切换上一章 / 切换下一章**。
  - `seekto`: 支持进度拖动。
- **进度同步**：在 `loadedmetadata`、`timeupdate`、`play`、`pause` 中调用 `navigator.mediaSession.setPositionState`，保持系统锁屏进度条毫秒级同步。

### 4.3 音频流式缓冲进度条
- **容器与结构**：在 `seek-track-wrapper` 内增加半透明缓冲进度层 `div.seek-buffer-bar`。
- **缓冲计算**：监听 `progress` 与 `timeupdate` 事件，遍历 `audio.buffered`，查找覆盖当前 `currentTime` 的缓冲片段，将其实际缓冲终点换算为百分比（`bufferedEnd / duration * 100%`）更新缓冲条宽度。

### 4.4 全局字幕与概念关键词搜索（Cmd+K / /）
- **触发与入口**：顶部工具栏增加搜索按钮，支持键盘快捷键 `Cmd+K`、`Ctrl+K` 与 `/` 唤起模态弹窗。
- **数据供给与预热机制（解决与懒加载冲突）**：
  - 首屏只同步加载当前章节数据，保障极致首屏速度；
  - 首屏渲染完成后，利用 `requestIdleCallback`（无则降级 `setTimeout`）在后台异步预热拉取未加载的章节数据；
  - 若用户在预热完成前呼出搜索框，界面显示“全书索引就绪中...”，优先展现已加载章节的搜索结果，预热完成后实时扩展为全书结果。
- **安全与 XSS 防护**：
  - 搜索关键词、命中句子文本必须经过严格的 HTML 实体转义函数处理；
  - 仅由受信任的渲染逻辑将安全文本包裹在 `<mark class="search-highlight">` 标签内，杜绝 DOM XSS 隐患。
- **交互与跳转**：
  - 支持中英文模糊匹配，展示结果列表（章节名、小节名、时间戳、匹配上下文），最多渲染前 50 条匹配项保障流畅度；
  - 点击任意条目自动关闭弹窗，若目标不在当前章则自动切章，并精确定位跳转至对应时间点。

### 4.5 单句时间戳深链接与快速分享
- **生成规范**：标准链接格式规范为 `reader.html#<chapterKey>?t=<seconds>`，例如 `reader.html#chapter2?t=154`。
- **复制与降级**：
  - Cue 卡片悬停/常显微型“复制链接”按钮；
  - 优先调用 `navigator.clipboard.writeText`；在非安全上下文（如本地非 HTTPS、局域网 IP 或特定 Webview）中自动降级使用 `document.execCommand('copy')`；
  - 复制成功或失败弹出明确轻提示 Toast（“链接已复制到剪贴板”）。
- **解析与优先级铁律**：
  - **URL 深链接优先级高于本地断点续播**：若 URL 含有 `?t=` 或 `-cueId`，优先跳至深链接时间点，并屏蔽本地历史进度的覆盖，同时更新本地进度为深链接起点。
  - **向下兼容解析正则**：采用 `^#?([a-zA-Z0-9_-]+)(?:[\?&](?:t|time)=([0-9.]+)|-([a-zA-Z0-9_-]+))?$`，兼容原有纯 `#chapterX` 格式。

### 4.6 睡眠定时器（Sleep Timer）
- **选项设置**：播放控制栏新增定时器菜单，提供：`15 分钟`、`30 分钟`、`45 分钟`、`播完本章后停止` 及 `关闭定时`。
- **倒计时提示**：按钮动态显示剩余分钟（如 `🌙 14m`），点击可随时取消或调整。
- **互斥与边界保护**：若激活“播完本章后停止”，系统自动解除单句复读（A-B Loop）状态，并在界面提示，防止陷入单句循环死锁。
- **平滑淡出**：定时结束前 10 秒，音量以线性步长平滑降至 0，随后执行 `audio.pause()` 并重置音量为原值。

### 4.7 快捷键扩充与输入焦点隔离
- **新增快捷键**：
  - `[` / `]`：微调播放速率（0.75x ~ 2.0x，步长 0.25x）。
  - `M`：静音 / 取消静音。
  - `/` 或 `Cmd+K`：唤起搜索框。
- **输入防冲突隔离**：当任何 `INPUT` 或 `TEXTAREA` 元素聚焦时，屏蔽所有单字符播放快捷键（如 `Space`, `[`, `]`, `M`, `R`, `L`, `/`），仅放行 `Cmd+K`、`Ctrl+K` 与 `Esc`。
- **帮助文档同步**：同步更新“键盘快捷键指南”弹窗中的条目。

### 4.8 章节数据按需懒加载与竞态控制
- **动态按需加载**：首屏仅静态加载 `chapters_meta.js` 与首个章节，其余章节切换时按需加载 `data/{chapterKey}.js`。
- **竞态保护**：维护当前激活的 `activeLoadToken`，若用户连续快速切换章节，仅最后一次切章请求生效，忽略过期的加载回调。
- **失败重试**：脚本加载失败触发重试提示 Toast。

### 4.9 音频网络异常与断网容错提示
- 监听 `audio.error`，在 CDN 加载超时或网络中断且本地未离线时，弹出“音频加载异常，请检查网络 [点击重试]”。

### 4.10 社交分享 Open Graph 卡片与 SEO 元数据
- 在 `index.html` 与 `reader.html` 中注入标准 `og:title`, `og:description`, `og:image`, `og:url`, `twitter:card`, `twitter:image` 以及 Schema.org `Audiobook` 结构化标记。

## 5. 不在本次范围（Out of Scope）
- 后端用户登录系统与跨设备云同步（严格保持 100% 静态纯前端，无后端依赖）。
- 音频重新生成或文本篡改（严格尊重原著与已生成的 21 小时音频对齐资产）。

## 6. 边界情况
- **首章初次访问**：无历史进度，从 00:00 正常播放，不触发恢复 Toast。
- **已播完的章节**：最后时间 >= duration - 5 秒时，重新进入从 00:00 开始，不跳至结尾。
- **深链接覆盖历史**：检测到有效时间戳参数时，深链接优先，不恢复旧进度。
- **不支持 MediaSession / LocalStorage 的浏览器**：通过特性检测降级，保证核心播放正常。
- **搜索空输入 / 无结果**：展示空态提示“未找到相关句子”，不报错。
- **深链接时间戳越界**：若 `t > duration`，自动限制为 `duration - 1`；若 cueId 不存在，回退到 00:00。
- **输入聚焦保护**：搜索框输入字符时不会误触发播放、静音或复读。

## 7. 成功标准（可验收）
- 播放 10 秒后刷新网页，进度准确恢复，Toast 提示正常，点击“从头开始”可重置。
- 在支持 MediaSession 的环境中，控制台无报错，锁屏控制指令正常回调。
- 搜索 "ReAct" 或 "上下文"，能在 50ms 内弹出包含章节、时间戳的高亮列表，点击跳转无误；HTML 实体安全无 XSS。
- 复制深链接并在新窗口打开，能精确唯一定位到指定时间并开始播放，且优于旧本地进度。
- 倒计时定时器结束时，音频音量平滑降为 0 并 pause。
- 首屏页面网络请求不全量加载 12 个章节，切换章节时动态拉取。
- 语法与静态检查 0 报错。
