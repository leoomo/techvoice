# 上下文工程 (Context) - echo-learning-mode

## 1. 目标与背景
本项目为开源技术有声书阅读器（TechVoice），核心承载李博杰《深入理解 AI Agent》21小时双语有声教材。
用户明确指示实现“第 3 项：🔁 权威‘回音精听循环’ (Echo Method / 史嘉琳三步法)”，用于显著提升技术英语学习效率。

## 2. 核心教学法 (Pedagogy)
台大史嘉琳教授（Prof. Karen Chung）提出的“回音法 (Echo Method)”包含三个不可或缺的关键环节：
1. **Listen (原速聆听)**: 完整听一遍原声音频，不分心，不跟读，专注于声调、停顿与连读弱读。
2. **Echo in Mind (留白回响)**: 播完后静默暂停约 2~3 秒，听觉神经短时记忆（Phonological Loop）在脑海中自动“重播”刚才听到的声音余音，让音调在大脑回路中巩固。
3. **Shadow & Mimic (微降速开口模仿)**: 再次播放同一句话（通常略微微降速至 0.85x，避免语速过快跟不上），读者同步大声跟读（Shadowing），用口腔肌肉精确模仿母语者口型与腔调。

## 3. 功能架构与交互形态
1. **单句精听 (Single Cue Echo)**:
   - 字幕卡片操作区新增 `Echo` 图标按钮。点击后立即针对该句子执行完整的 3 步回音精听，完成后暂停于该句。
2. **连续回音流模式 (Continuous Echo Stream)**:
   - 底部工具栏新增 `Echo 模式` 切换开关（快捷键 `E`）。
   - 开启后，整章有声书自动以“句句回音”节奏持续推进入耳（适合通勤散步、做家务时的沉浸式伴学口语磨耳朵）。
3. **视觉状态反馈**:
   - Step 1 (Listen): 正常高亮播放；
   - Step 2 (Echo): 卡片显示 `🧠 留白回响 (Echo in mind)...` 状态提示与微进度呼吸动效；
   - Step 3 (Shadow): 卡片显示 `🎙️ 跟读模仿 (Shadowing)...` 状态提示。
4. **互斥守卫与边界兼容**:
   - 与 A-B Loop 互斥：开启 Echo 自动解除单句复读；开启单句复读自动解除 Echo。
   - 与 Sleep Timer 协同：睡眠定时暂停时清理所有 Echo 状态，恢复原始语速。
   - 手动暂停/跳章：按 Space 暂停或切章时，立即清理在途的回响定时器并恢复原始语速。
   - 100% 静态纯前端，零外部构建/npm 依赖。
