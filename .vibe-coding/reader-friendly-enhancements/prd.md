# PRD: reader-friendly-enhancements (阅读体验友好度全面升级)

## 1. 背景与问题
TechVoice 是面向《深入理解 AI Agent：设计原理与工程实践》全书 12 章节、20 余小时的双语有声精读小站。用户在平台上既是“听众”，更是“深度阅读与学习者”。
在日常使用中有两大核心阅读痛点亟待解决：
1. **视觉光晕与日间可读性缺陷**：
   - 白天（Light Mode）使用冷蓝灰底色（`#f8fafc`）与纯白卡片，加上 94% 高反差纯黑墨字（`#0f172a`），在白天日光下长时间注视产生强烈的屏幕眩光与视网膜疲劳；
   - 首页书本封面文字硬编码为 `#ffffff` 与 `#f8fafc`，在白天模式白底上出现严重的“白字白底隐形”现象；
   - 跟读三步法的徽标颜色沿用暗色浅绿与明黄，在白天浅底上对比度仅 1.6:1 ~ 1.8:1，严重发虚发飘；
   - 缺少 `--accent`, `--bg-surface`, `--text-faint`, `--bg-hover` 等必要变量，导致进度条小节刻度点在白天下隐形。
2. **滚动抢夺与阅读打扰（The Scroll Hijack Problem）**：
   - 只要开启了“自动跟随”，每过 3~5 秒下一个句子开始播放时，页面就会调用 `scrollIntoView` 强行把屏幕拽回播放位置。
   - 当用户想往上翻看前两段的代码定义、或者往下预览接下来的架构推演时，屏幕会被反复强制拽回，产生极度痛苦的“抢夺滚动条”体验。

## 2. 目标用户
- 开发者、AI 架构师、系统工程师、在通勤、工位或散步时精听精读技术英文的严肃学习者。

## 3. 核心使用场景
- **场景 A（温润护眼阅读）**：用户在白天办公室或靠窗阳光下连续阅读 30 分钟技术书，页面底色呈现出如出版级纸张般的温润象牙色，正文边缘柔和不刺眼，排版行宽符合人眼最佳扫视范围。
- **场景 B（从容查阅上下文）**：用户听着第 50 句，想向上翻阅第 43 句的术语定义。播放器识别到用户的主动滚动，静默停止拽屏；右下角浮出微型胶囊 `🎯 回到播放处`。用户看懂后点击一下瞬间平滑滑回，体验连贯无阻。
- **场景 C（清晰辨识跟读阶段）**：用户在白天光线下开启三遍跟读，1.0x 听（天蓝）、0.85x 读（翠绿）、1.0x 巩固（金黄）三阶段徽标文字清晰饱满，对比度全部达到 WCAG AA/AAA 高清晰标准。

## 4. 功能范围（In Scope）
1. **Feature 1: 出版物级“纸感温润微调与日间调色校准”（Warm Paper & Rich Ink）**
   - 将日间底色从冷灰蓝 `#f8fafc` 升级为温润微暖纸色（`#fbfbfa` / `#fafaf9`）；
   - 正文墨色调校为富墨色 `#1e293b`（对比度 12.6:1 超 AAA 标准，边缘柔和不刺眼），中文字色设为清晰次级灰 `#334155`（对比度 8.2:1）；
   - 修复首页书本封面硬编码白字隐形缺陷（改用语义变量 `var(--text-main)` 与 `var(--text-muted)`）；
   - 补齐并对齐 CSS 变量系统：在 `style.css` 和 `landing.css` 中建立别名桥接（`--text-main: var(--text-primary)`, `--text-secondary: #475569`, `--accent: var(--text-accent)`, `--bg-surface`, `--text-faint`, `--bg-hover`），确保组件跨页面无缝回退，绝不破坏深色模式；
   - 修复进度条小节刻度点在白天下白点隐形的问题（白天改用 `rgba(15, 23, 42, 0.2)`，hover 品牌蓝高亮）。
2. **Feature 2: 排版行气与行宽约束（Typography & Reading Measure）**
   - 约束阅读视区最大宽度为 `820px`（约 68-72ch 黄金舒适行宽），眼球横向扫视不窜行；
   - 英文正文字号提升至 `16.5px`，行高舒展至 `1.65`；中文副译文字号优化为 `14px`，行高 `1.6`；中英文纵向间距优化至 `6px`，段落呼吸感更强；
   - 增加全局自定义选区高光（`::selection`），划词查词呈现专属柔和天蓝微透质感。
3. **Feature 3: 朗读句“马克笔呼吸锚定”（Active Reading Anchor）**
   - 正在播放的句子卡片在白天下使用柔和的 Sky-50 天幕高光底色（`#f0f9ff`）+ `3.5px solid #0284c7` 左边界；
   - 当前朗读英文加深聚焦（`#0369a1`），用户转头喝水后视线回到屏幕，0.1 秒内精准锚定当前行。
4. **Feature 4: 跟读三步徽标日间高清晰度升级**
   - 第 1 步原速听：文字 `#0284c7`（5.2:1），底色 `rgba(2, 132, 199, 0.08)`；
   - 第 2 步降速读：文字 `#15803d`（4.9:1），底色 `rgba(22, 163, 74, 0.08)`；
   - 第 3 步原速巩固：文字 `#b45309`（5.4:1），底色 `rgba(217, 119, 6, 0.08)`。
5. **Feature 5: 智能防打扰阅读滚动与“回到播放处”胶囊导引**
   - 建立“用户临时脱离跟随”（`isUserDetached`）状态机，与用户持久化的全局自动跟随设置（`state.autoScroll`）彻底解耦；
   - 监听主滚动容器 `.transcript-container` 的全量滚动事件（以容器 `scroll` 为主，并辅以 `wheel`、`touchmove`、键盘翻页等手势识别），通过程序滚动锁（`isProgrammaticScrolling`）精准区分代码驱动的平滑滚动与用户主动浏览（包含拖动滚动条滑块、滚轮、触屏手势、PageUp/PageDown）；
   - 用户主动向上/向下翻阅时，标记 `isUserDetached = true`，在此期间静默暂停程序拉扯，严禁任何超时强制夺取屏幕控制权；
   - 当正在播放的句子离开容器可视范围（以 `#transcript-list` 为视口基准）时，右下角优雅浮现胶囊按钮：`🎯 回到播放处 (Resume to active sentence)`；
   - 点击该胶囊后，平滑滚动回到当前句，并重置 `isUserDetached = false` 恢复跟随锁定；若用户手动把当前播放句滑回容器可见区域，亦自动重置 `isUserDetached = false` 并隐去胶囊；绝不武断进行倒计时强行滚回。

## 5. 不在本次范围（Out of Scope）
- 不修改底层音频合成、切片与时间对齐数据；
- 不引入外部复杂前端框架或大型 UI 库；
- 不改动暗色模式现有深邃沉浸的基调。

## 6. 边界情况
- **程序滚动与用户滚动的可靠区分**：在 `highlightCue` 触发 `scrollIntoView` 前设置 `isProgrammaticScrolling = true`，滚动结束后延时释放，彻底杜绝程序平滑滚动误触发用户脱离。
- **状态机解耦与开关防篡改**：若全局 `state.autoScroll === false`（用户手动关闭跟随），浮动胶囊始终保持隐藏，用户无论如何滚动均不展示胶囊，点击任何区域均不得篡改用户持久化的 `state.autoScroll` 偏好。
- **全输入源主动滚动捕获**：除滚轮与触摸外，鼠标拖拽滚动条滑块（产生 `scroll` 无 `wheel`）、点击轨道、键盘翻页按键，均能被可靠捕获并进入主动阅读态。
- **容器视口精准判定**：滚出判定基准必须限定在 `#transcript-list`（`.transcript-container`）的可视盒模型内（计算 `getBoundingClientRect()` 相对于容器边界），避免顶部吸顶栏（`top-bar` 52px 与 `player-container` 80px）遮挡产生假阳性判定。
- **章节切换与点击跳转重置**：切章、点击小节目录或主动点击某句卡片播放时，立即重置 `isUserDetached = false`，隐藏胶囊并锁定新目标。
- **移动端视口避让**：浮动胶囊在手机屏幕上必须避让顶部导航与底部悬浮控制器，支持安全区域 `env(safe-area-inset-bottom)`。
- **多语言即时响应**：浮动胶囊文案通过 `TechVoiceI18N` 联动，支持实时动态中英文切换。
- **环境隔离防御**：所有 DOM 与 BOM 监听均添加 `typeof window !== 'undefined'` 守卫，保证 Node.js 环境下自动化测试 100% 安全执行。

## 7. 成功标准（可验收）
1. 白天模式下所有文本、徽标与卡片底色的对比度 100% 达到 WCAG AA (>=4.5:1) 或 AAA (>=7.0:1)；
2. 首页图书封面在白天模式下书名、副标题、作者清晰可见；
3. 用户在播放过程中滑动浏览上下文，页面不会在句子跳变时粗暴拽屏；
4. 滚出视野后浮现“回到播放处”胶囊，点击后平滑回到当前句；
5. 全量 12 套自动化测试全部通过，新增测试覆盖上述新逻辑。
