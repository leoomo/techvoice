## 3. 关键架构与设计经验

### 3.1 去眩光（Anti-Halation）与焦点层级
在暗黑背景（`#0b0f19`）下，纯白文本（`#ffffff`）的对比度高达 19.8:1，暗光环境下由于人眼瞳孔放大，高频白字边缘会产生严重的光晕散射（Halation）。
- **解决方案**: 将长篇阅读中的背景/非激活正文软化为冷岩灰 `#cbd5e1`（10:1 对比度），仅在当前音频播放激活的单句上赋予防眩纯白聚焦 `#ffffff`。
- **效果**: 视线无需搜寻即可瞬间锁定播放流，长时间沉浸听读眼睛无酸胀感。

### 3.2 边框等宽设计实现 Zero-CLS（零累积布局位移）
当非激活卡片无边框（或不同步频状态边框宽度不一致）时，切句或切换跟读状态会导致卡片内部排版发生 0.5px ~ 3.5px 的横向位移跳动。
- **解决方案**:
  1. 基础 `.cue-card` 静态预留 `border-left: 3.5px solid transparent;`；
  2. 常规激活句配置 `border-left: 3.5px solid #38bdf8;`；
  3. 跟读四步状态全部声明 `border-left: 3.5px solid ... !important;`（Listening 步同步由原本的 3px 升级为 3.5px）；
  4. 中文字幕全量统一步频 `line-height: 1.68`，防止卡片高度随激活态动态变化产生垂直跳动。
- **效果**: 音频跨句流动或状态步进时，字幕列表完全平稳，无任何微小视觉震颤。

### 3.3 严格的作用域防线与 CSS 特异性治理
- **防线设计**: 所有暗色特化规则严格限制在 `:root:not([data-theme="light"])` 作用域下，杜绝裸全局类名污染白天浅色模式。
- **特异性治理**: 严禁使用裸 ID 选择器 `#btn-resume-cue` 定义暗色样式，防止其 `(1, 0, 0)` 权重压制白天模式的 `[data-theme="light"] .btn-resume-cue` `(0, 2, 0)`。通过统一使用类选择器 `.btn-resume-cue`，确保暗色基准与白天覆盖优雅共存。
