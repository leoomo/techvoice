# PRD: dark-mode-reading-enhancements (黑夜模式阅读体验全面升级)

## 1. 背景与问题
在弱光或夜间环境下，读者阅读与精听长篇技术书时，现行黑夜模式存在以下明显体验痛点：
1. **满屏大白字光晕眩光（Halation / Optical Bloom）**：默认所有非激活英文均为高亮纯白（`#f8fafc`），在 `#080c14` 极黑底色上对比度达 19.8:1，长篇阅读时瞳孔放大，高频发光的文字边缘产生强烈毛刺眩光，极易引起视觉疲劳；
2. **缺乏视觉焦点（Flat Visual Hierarchy）**：当前播放句与未播放句字色完全一致，仅凭一条细左边框与极微弱的 6% 浅蓝底色，夜间余光扫视时极难快速定位发声位置；
3. **双语中文字幕暗淡粘连**：当前句激活时，中文字幕依然保持暗灰 `#94a3b8`，且汉字繁复笔画在夜间易产生灰度粘连，双语对照费力；
4. **跟读徽标荧光刺眼**：回音跟读模式中的部分徽标在纯黑背景下带有刺眼的“霓虹灯/荧光笔”感；
5. **悬浮控件生硬**：“回到播放处”胶囊在暗色下为实色块，缺乏沉浸式通透感。

## 2. 目标用户
- 夜间通勤、散步或睡前静听精读开源技术书的技术读者与英语学习者。

## 3. 核心使用场景
- **场景 A（夜间长时阅读）**：读者在暗光下连续精听 30 分钟以上，周围文字温和沉静不刺眼，当前朗读句如马克笔微光般自然聚焦。
- **场景 B（双语对照速览）**：读者听到某生词或复杂概念时扫视屏幕，当前句的英文与中文译文同时高光提亮，汉字笔画疏朗清晰，瞬间完成心智映射。
- **场景 C（回音跟读模式）**：读者开启跟读练习时，听、读、巩固、回音四步徽标优雅提示，色彩柔和具工程美感，无荧光眩光干扰。
- **场景 D（翻阅上下文自愈）**：读者向上翻看前文时，磨砂深色胶囊通透浮现，不生硬遮挡，点击平滑飞回。

## 4. 功能范围（In Scope）
- **F-1: 非激活句文本光晕消除与层次软化（防止全局变量污染）**：
  - 暗色模式下，限定阅读字幕卡片普通未激活英文正文调整为清润冷岩灰 `#cbd5e1`（Slate-300，对比度约 10:1，极度清晰且彻底消除眩光发光毛刺）；
  - **严格局部作用域**：仅作用于 `:root:not([data-theme="light"]) .cue-card:not(.active) .en-text`，绝不修改全局 `--text-primary`，确保顶部导航栏、侧边栏、弹窗标题等核心层级不塌陷；
- **F-2: 当前朗读句“深海天幕锚定（Deep Ocean Glow）”与零位移（Zero-CLS）防抖**：
  - 基础 `.cue-card` 的默认透明左边框统一对齐预留为 `border-left: 3.5px solid transparent`，彻底消除切句激活时边框宽度突变导致的水平文字抖动（CLS）；
  - 当前激活卡片背景调整为深邃通透的深海蓝 `rgba(56, 189, 248, 0.11)`；
  - 左侧马克笔边界加粗为清澈冰川蓝 `3.5px solid #38bdf8`；
  - 边框赋予微光 `border-color: rgba(56, 189, 248, 0.28)`；
  - 引入深色克制幽蓝微光阴影：`box-shadow: 0 4px 20px -2px rgba(56, 189, 248, 0.14)`；
  - 当前句英文正文独享纯净纯白高光聚焦 `#ffffff`，字重 `550`；
  - 时间戳徽标同步提亮为冰川蓝微光胶囊；
- **F-3: 中文译文暗夜行气调优与双语同步提亮（严格暗色作用域，绝不污染白日模式）**：
  - **严格暗色作用域隔离**：使用 `:root:not([data-theme="light"]) .cue-card.active .zh-text` 选择器，当前句中文字幕从暗灰 `#94a3b8` 同步提亮为清润亮灰 `#e2e8f0`（Slate-200）；严禁使用无主题限定的全局 `.cue-card.active .zh-text`，确保白天模式在 `#f0f9ff` 浅底上绝不出现浅灰隐形崩塌；
  - **统一静态行距消除抖动**：将暗色模式下所有字幕卡片的 `.zh-text` 统一步频设为 `line-height: 1.68`，为复杂汉字笔画留足透光空隙，消除夜间粘连；不依赖激活状态动态改变行高，杜绝卡片高度动态跳闪；
- **F-4: 跟读四步徽标暗夜去荧光微光调校（含回音第 4 步状态）**：
  - 覆盖 `EchoController` 的全部 4 步状态，降低高饱和荧光感，改用半透明微光磨砂质感：
    - 听（Listening）：`color: #38bdf8; background: rgba(56, 189, 248, 0.16); border-color: rgba(56, 189, 248, 0.35);`
    - 读（Shadowing）：`color: #34d399; background: rgba(16, 185, 129, 0.14); border-color: rgba(16, 185, 129, 0.3);`（软化翡翠绿，消除刺眼荧光绿）
    - 巩固（Reviewing）：`color: #f59e0b; background: rgba(245, 158, 11, 0.14); border-color: rgba(245, 158, 11, 0.3);`（暖琥珀）
    - 回音（Echoing）：`color: #a78bfa; background: rgba(168, 85, 247, 0.14); border-color: rgba(168, 85, 247, 0.3);`（柔和淡紫）
- **F-5: “回到播放处”胶囊暗夜深色毛玻璃通透感（类选择器避免权重穿透）**：
  - 统一使用类选择器 `.btn-resume-cue` 与 `:root:not([data-theme="light"]) .btn-resume-cue`，严禁在 CSS 中使用裸 ID 选择器 `#btn-resume-cue`，确保特异性严格低于 `[data-theme="light"] .btn-resume-cue`（0, 2, 0），零污染白天模式：
    - `background: rgba(13, 18, 29, 0.85);`
    - `backdrop-filter: blur(16px); -webkit-backdrop-filter: blur(16px);`
    - `border: 1px solid rgba(56, 189, 248, 0.3);`
    - `box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.6), 0 0 12px rgba(56, 189, 248, 0.15);`
- **F-6: 离线缓存与全量测试闭环升级**：
  - `sw.js` 缓存版本升级至 `ai-agent-shell-v7`；
  - 同步更新 `tests/test_sw_and_error.js` 中的测试断言匹配为 `ai-agent-shell-v7`，确保测试套件无缝对齐；
  - 运行全量 13 套自动化测试套件；
  - 合并 `master` 并推送至 GitHub 远端仓库正式发布。

## 5. 不在本次范围（Out of Scope）
- 不修改刚刚发布且验收通过的白天模式（`[data-theme="light"]`）微暖纸感规则；
- 不引入外部字体、外部 UI 库或打包依赖；
- 不变更底层音频切句与状态机接口签名。

## 6. 边界情况
- **单模式视图与双语切换**：在纯英文模式（`hide-zh`）与纯中文模式（`hide-en`）下，样式规则必须无破损；
- **跟读模式与常规模式叠加**：跟读进行时卡片具有 `.echo-step-*` 类，其优先级须自然覆盖普通激活状态；
- **白昼/暗夜切换无跳闪**：日间与黑夜互相切换时，所有变量和特化类名过渡平滑（`transition: 0.15s~0.2s`），无残影或突兀色彩溢出；
- **小屏与大屏一致性**：在移动端响应式布局下，光晕阴影与深海天幕保持轻量流畅，无 GPU 掉帧。

## 7. 成功标准（可验收）
- **文字层次分明**：暗色模式下非激活英文正文呈现柔和冷岩灰（`#cbd5e1`，对比度约 10:1），当前播放句英文呈现高亮纯白（`#ffffff`，字重 550），主次一眼可见；
- **双语同步高光**：当前句的中文字幕由次级暗灰提升至亮灰（`#e2e8f0`），中文汉字在黑夜下字迹疏朗，无粘连感；
- **深海天幕沉浸锚定与零抖动**：当前卡片在黑夜下拥有清晰的深海蓝背景（`rgba(56, 189, 248, 0.11)`）与微光阴影，卡片与边框在切句过程中无任何横向或垂直抖动；
- **白天模式 100% 隔离**：在 `[data-theme="light"]` 激活时，所有浅色规则（暖纸色、富墨色、深林绿等）完全不受任何负面影响，中文字幕绝不出现浅灰隐形；
- **自动化测试 100% 绿灯**：全量 13 套自动化测试持续通过，Service Worker 缓存断言与实现完全一致；
- **线上发布就绪**：成功 push 到 GitHub `master`。
